# Notes
- Calculating the size of an array using the size in bytes of the data types,
e. g. `sizeof(array)` / `sizeof(element)` = amount of elements
- "Iteration" = Going through an `array` one by one, instead of just calling an `element` once
- `for each loop` = Less code but also less flexibility, `for(datatype + name : array)`
- Personal Note = Integers make your life easier...
- "SortArray" function = Double iteration + using a temp variable
- Do not forget about whitespaces, empty spaces, temp variables and `break`...
- A 2D-Array only has as many elements as rows. The Values within the rows belong to the rows and not to the 2D-Array. Basically multiple arrays inside an array. Array(Parent) -> Rows(Child) -> Columns(Grandchild).
