# 02 Variables & Simple Data Types

# Goal
Understand and use variables and simple data types

# Code
Look: `src/02_variables.cpp`

# Notes
- variables = first declare then assign
- build sentences = can put strings *behind or in front* of variables
- `<<` = used for multiple parts
- `;` = ends "code-line"
- `int` = whole number
- `double` = decimal number
- `char` = single character
- `bool` = true/false
- `std::string` = text
