# Notes
- A pointer is a `variable` that stores the `memory address` of another `variable`
- Everything inside the RAM has a memory address, which is the "identity" of e.g. a variable, an array, a function etc.
- `&` = Address-of operator (before a variable to access the memory address)
- `*` = Dereference operator (before a variable to create a pointer) (before a pointer to access the value instead of the address of the variable)
- `nullptr` = Is a keyword for a value without a value
- Be careful not to use a `pointer` which points to nothing (`nullptr`)
