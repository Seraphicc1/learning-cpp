# Goal
Learn some basics about structs

# Code
Look: `src/36_structs.cpp`

# Notes
- Instead of storing different values of the same datatype like an `array`, you can store different values of diferent datatypes using a `struct`
- `struct x{}` = to create a struct
- `variables` inside a `struct` are called "members"
- You can create `variables` using the `struct` which acts like a datatype
- `.` = "Class Member Access Operator" used to access `variables` inside a struct using the created `variable`
- Passing a `struct` into a function passes it by value, making a copy of it with new `memory` allocated to the copy
