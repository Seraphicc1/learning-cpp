# 18 Do While/While/For Loops

# Goal
Learn about the different loops and use them

# Code
Look: `src/18_loops.cpp`

# Notes
- `while` = Can be used to force user input
- `while` = Needs a way to exit or it becomes infinite
- `do while` = Does block of code first, then starts the while loop
- `do while` = Could be useful for a game (Run game -> does user want to play again? -> repeat)
- `for` = Used to run a block fo code for a specific amount of times
- `continue` = Use to skip current iteration
- `break` = Use to break out of the loop
