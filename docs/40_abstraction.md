# 40 Abstraction

# Goal
Use getters and setters to acces private class attributes

# Code
Look: `src/40_abstraction.cpp`

# Notes
- `get` function inside the `public` section allows to make a private attribute readable
- `set` function inside the `public` section allows to make a private attribute writable
- You can invoke the `setter` inside the `constructor` to change the attribute
